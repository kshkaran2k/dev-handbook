# Dev Handbook

A personal knowledge base of learnings from my day-to-day work as a developer — covering cloud, databases, system design trade-offs, debugging notes, and anything else worth remembering for later.

The goal isn't a polished tutorial series, but a growing reference I (and hopefully others) can come back to when facing a familiar problem, making an architecture decision, or just trying to recall *why* I chose one approach over another.

## What's inside(Coming Soon)
- **Concepts & trade-offs** — comparisons like SQL vs NoSQL, embedding vs referencing, monolith vs microservices, etc.
- **Databases** — deep dives per database (data modeling, indexing, performance considerations)
- **Debugging logs** — real issues I've hit, how I diagnosed them, and how they were fixed
- **Cloud** — notes on AWS/GCP/Azure services and when to use what

## Current contents
- [`mongodb.md`](databases/mongodb.md) — MongoDB overview + data modeling guidelines (embed vs reference), with worked examples

More topics will be added. Contributions, corrections, or suggestions are welcome via issues/PRs.
